# GestoTrafic · CRM para gestorías de tráfico

Demo comercial de **WhiteMoon Agencia IA** — CRM para gestorías administrativas
especializadas en trámites de tráfico, con la **Calculadora ITP** integrada.

> 🟣 **DEMO** · Datos de ejemplo. No es un entorno de producción.

---

## ⛔ Alcance regulado

GestoTrafic **NO se conecta con la DGT ni con la Agencia Tributaria**, y no
presenta expedientes ante ningún organismo.

La gestoría presenta el expediente con el programa oficial de su colegio.
Lo que hace este CRM es dejar el expediente **listo para presentar**:
datos completos, impuestos calculados, documentación capturada y contrato
generado.
